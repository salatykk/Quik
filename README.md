# Quik

**Desktop Widget Platform** — буферы‑виджеты, полноэкранный оверлей и встраивание сторонних приложений в одном рабочем пространстве для Windows.

## Возможности

- **Десктоп‑виджеты** — прозрачные, безрамочные окна поверх рабочего стола: перетаскивание, изменение размера, масштаб 60–200%, прозрачность
- **Полноэкранный оверлей** (бардак‑дашборд) — вызывается по `Ctrl+Shift+Tab`
- **Встраивание приложений** — запуск `.exe` или URL прямо внутри оверлея (Win32 через FFI, без нативных аддонов)
- **Быстрый запуск** — панель приложений в сайдбаре оверлея
- **Музыка** — текущий трек из Windows через SMTC
- **Погода, криптовалюты, карты** — Open‑Meteo, CoinGecko, Nominatim/OSM
- **Темы** — 4 пресета (Emerald, Liquid Glass, Midnight, Ember) + настройка акцента, шрифтов и радиуса
- **Системный трей**, автозапуск, глобальный хоткей, локализованный установщик
- **Автообновления** — проверка по GitHub Releases (установщиком), уведомление, загрузка и установка только с согласия пользователя

## Виджеты

| Виджет | Описание |
| --- | --- |
| Часы | время и дата на русском |
| Погода | текущая погода, несколько городов, SVG‑иконки |
| Музыка | исполнитель, трек, прогресс, состояние воспроизведения |
| Крипта | BTC, ETH, SOL, DOGE, ADA, XRP + динамика за 24ч |
| Карты | поиск мест и встроенная карта |

## Технологии

Electron · React · TypeScript · Vite · koffi (Win32 FFI) · electron-builder

## Сборка

```bash
npm install

# разработка
npm run dev

# установщик + portable (Windows x64)
npm run dist
```

Артефакты появятся в `dist/`:
- `Quik-Setup-<version>.exe` — установщик (с лицензионным соглашением, ru)
- `Quik-<version>-portable.exe` — переносная версия

## Обновления

При запуске установленного приложения автоматически проверяются релизы на GitHub: https://github.com/salatykk/Quik/releases

Если доступна новая версия, пользователь получает уведомление. Список изменений отображается в модальном окне оверлея. Загрузка и установка выполняются только с явного согласия.

Обновление ищет в релизе файл `Quik-Setup-{версия}.exe` (portable-версия игнорируется), скачивает его в папку приложения и автоматически запускает установщик. После завершения обновления при первом запуске показывается, что нового.

## Релиз

```bash
# Requires GH_TOKEN environment variable with a GitHub PAT (repo scope)
npm run release
```

Команда собирает установщик, portable и публикует артефакты + `latest.yml` в GitHub Releases. Это автоматически связывает обновление с тегом релиза.
